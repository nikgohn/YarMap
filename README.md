# 🗺️ YarMap — Интерактивный геопортал исторических планов Ярославля

Современный легковесный веб-просмотрщик для наложения, сопоставления и исследования архивных генеральных планов, градостроительных чертежей и исторических выкопировок города Ярославля поверх актуальных спутниковых снимков и картографических подложек.

🌐 **Онлайн-версия**: [https://study.nikgohn.ru/YarMap/](https://study.nikgohn.ru/YarMap/)

---

## ✨ Возможности

- **Два режима исследования**:
  - **«Наложение»**: одновременное включение любого количества исторических слоев с индивидуальной регулировкой прозрачности (0–100%) для каждого плана.
  - **«Сравнение» (Шторка / Swipe)**: интерактивное разделение экрана для наглядного сравнения архивного чертежа с современным спутником в реальном времени.
- **📍 Пространственный поиск по маркеру**:
  - Кликните кнопку *«Маркер»* и поставьте метку в любую точку города — панель мгновенно отфильтрует только те исторические планы, которые покрывают выбранное место. Метку можно свободно перетаскивать по карте.
- **🔍 Текстовый поиск**: быстрая фильтрация по названию, периоду/году или идентификатору плана.
- **🎯 Фокусировка на плане**: кнопка центрирования мгновенно подстраивает масштаб и область видимости камеры точно под границы выбранной карты (`fitBounds`).
- **ℹ️ Подробная архивная справка**:
  - Описание плана, масштаб чертежа, назначение, датировка и источник/архив.
  - Кнопка быстрого просмотра и скачивания **оригинального полноразмерного скана**.
- **🌍 Современные базовые подложки**:
  - **ESRI World Imagery** (детализированный мировой спутник)
  - **Яндекс Спутник и Гибрид** (с бесшовной синхронизацией проекций и правильным порядком наложения)
  - **Google Спутник и Гибрид**
  - **OpenStreetMap** (подробная топографическая карта)
  - **CartoDB Dark / Light** (контрастные дизайнерские подложки)
- **🔎 Сверхглубокий зум (до 22 уровня)**: просмотр мельчайших деталей чертежей без исчезновения тайлов при сильном приближении (`maxNativeZoom: 19`, `maxZoom: 22`).
- **📱 Адаптивный Glassmorphism UI**: удобная боковая панель со списком карт, адаптированная под экраны любых разрешений, скрываемая в компактный вид.

## 📁 Структура проекта

```text
YarMap/
├── index.html                  # Основной веб-интерфейс (Leaflet, стили, логика)
├── server.js                   # Локальный сервер разработки (Bun / Node)
├── update_maps.py              # Скрипт авто-сканирования, расчёта bounds и очистки EXIF (Python)
├── update_maps.js              # Скрипт авто-сканирования и регистрации карт (Bun/Node)
├── maps/
│   ├── maps.json               # Реестр активных карт (генерируется автоматически)
│   ├── template.info.json      # Шаблон конфигурационного файла для новых карт
│   ├── map1/                   # Папка карты: выкопировка 1:5000 (1950–1960-е)
│   │   ├── .map/
│   │   │   ├── info.json       # Метаданные (название, границы, масштаб, описание)
│   │   │   └── original.jpg    # Исходный скан высокого разрешения
│   │   └── 12/ ... 19/         # Каталоги тайлов XYZ
│   ├── map2/                   # Ситуационный план гостиницы и кинотеатра
│   ├── map3/                   # Выкопировка под жилой дом ЯШЗ 1:1000
│   ├── zv_1mkr/                # Генплан 1-го мкр. Заволжского р-на (Часть 1: школы, спортядро)
│   └── zv_1mkr_pt2/            # Генплан 1-го мкр. Заволжского р-на (Часть 2: жилая застройка)
└── .github/workflows/
    └── deploy.yml              # Автоматический деплой на GitHub Pages
```

## 🛠️ Как добавить новую карту

Система полностью модульная и не требует ручной правки HTML-кода:

1. **Экспорт тайлов из QGIS**:
   - Привяжите растровый план в QGIS к координатам (EPSG:3857 / EPSG:4326).
   - В панели инструментов выберите **Генерация тайлов XYZ (Каталог)**.
   - Задайте диапазон зумов (рекомендуется `12..19`).
   - ⚠️ **Формат тайлов**: обязательно выбирайте **`PNG`**, чтобы границы карты были прозрачными и не перекрывали соседние слои белым фоном.
   - Укажите путь вывода в папку проекта: `maps/<id_карты>` (например, `maps/map_1910`).

2. **Добавление скана оригинала (по желанию)**:
   - Создайте внутри `maps/<id_карты>/` папку `.map/` и положите туда графический файл оригинала (`original.jpg` или `original.png`).

3. **Автоматическая регистрация**:
   Запустите скрипт обновления:
   ```bash
   python update_maps.py
   # или:
   bun update_maps.js
   ```
   *Скрипт автоматически:*
   - Определит все зумы и формат тайлов;
   - Рассчитает географические границы (`bounds`) для маркера и зума;
   - Создаст файл `.map/info.json`;
   - Очистит EXIF-метаданные и запечет ориентацию скана (в версии `update_maps.py`);
   - Обновит список в `maps/maps.json`.

4. **Заполнение описания**:
   - Откройте сгенерированный `maps/<id_карты>/.map/info.json` и укажите название (`title`), год (`year`), описание (`description`) и источник (`source`).

## 🚀 Локальный запуск

Для запуска веб-интерфейса локально достаточно запустить любой статический HTTP-сервер:

### Через Bun:
```bash
bun server.js
```
Откройте браузер по адресу [http://localhost:3000](http://localhost:3000).

### Через Python:
```bash
python -m http.server 3000
```

Проект настроен для автоматической публикации на **GitHub Pages**:

```bash
git add .
git commit -m "Add new historical map"
git push
```
