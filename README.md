# Исторические карты и разметка города (Ярославль)

Интерактивный веб-просмотрщик исторических планов и старых разметок города с привязкой к современной спутниковой карте.

## Возможности
- **3 исторических плана**: раздельное включение, настройка прозрачности (0–100%).
- **Режим «Шторка» (Swipe)**: сравнение старых карт с современным спутником в реальном времени.
- **Подложки**: ESRI Satellite, Google Satellite, Яндекс Спутник, OpenStreetMap, CartoDB Dark.
- **Глубокий зум**: поддержка зума вплоть до 22-го уровня.
